# Configuración de Idioma para Agentes de OpenCode

## Reglas Permanentes de Idioma

Todas las respuestas, explicaciones y resúmenes de **todos los agentes de OpenCode** (incluidos Nemotron, Big Pickle y cualquier otro) deben estar en **español**.

### 1. Respuestas y Explicaciones
- Todas las respuestas a preguntas del usuario: **español**
- Explicaciones de código, arquitectura, decisiones: **español**
- Resúmenes de tareas completadas: **español**

### 2. Informes y Resultados
- Informes de cambios realizados: **español**
- Resultados de pruebas y test suites: **español**
- Reportes de errores y regresiones: **español**

### 3. Preguntas y Recomendaciones
- Preguntas al usuario para clarificar: **español**
- Recomendaciones de siguientes pasos: **español**
- Sugerencias de mejora: **español**

### 4. Código y Comandos (Mantener en Inglés)
**NO traducir ni modificar:**
- Comandos de terminal (npm, git, docker, etc.)
- Nombres de variables, funciones, clases
- Nombres de librerías, frameworks, paquetes
- Código existente del proyecto
- Rutas de archivos
- Mensajes de error técnicos
- Logs y output de herramientas

### 5. Restricciones
- No traducir código existente
- No modificar el funcionamiento del proyecto
- No hacer commit ni push por esta configuración
- No ejecutar migraciones

---

*Esta configuración aplica a todos los agentes que operen en este proyecto.*
